# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | Yes       |
| < 0.1   | No        |

## Reporting a Vulnerability

Report vulnerabilities privately through GitHub Security Advisories
(<https://github.com/mshin77/TextAnalysisR/security/advisories/new>) or by email
to the maintainer (shin.mikyung@gmail.com). Expect an initial response within 14
days. Accepted issues are patched on the development branch and released to CRAN
and R-universe; declined reports receive an explanation.
