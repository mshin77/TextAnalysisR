## Language Support

Primary language: English. Support varies by feature.

### Multilingual

- Preprocessing, DFM, TF-IDF, log-odds, lexical diversity (stopwords for 50+ languages)
- Topic modeling (STM) on any tokenized corpus
- BERTopic and embeddings with a multilingual embedding model
- AI features (labels, content, RAG, LLM sentiment) via OpenAI or Gemini

### English only

- spaCy analysis (lemmatization, POS, NER, dependency)
- Sentiment lexicons (AFINN, Bing, NRC)

### Interface

The globe icon (top right) translates the interface into 100+ languages via Google Translate — display only, not the analysis.
